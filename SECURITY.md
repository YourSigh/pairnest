# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability or include
private PairNest data in a report.

After the GitHub repository is created, use its private vulnerability
reporting or Security Advisory feature when available. If that channel is not
available, email `1325285734@qq.com` with the subject `PairNest Security`.

Include the affected version, deployment context, reproduction steps, impact,
and a minimal proof of concept. Remove access tokens, relationship data,
database contents, uploaded media, and other personal information before
sending the report.

No response-time or support SLA is promised for PairNest v0.1.

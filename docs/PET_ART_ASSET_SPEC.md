# 共同养宠美术资源规格

## 总体要求

- 画布：角色序列帧每张 `1024 × 1024 PNG`，场景 `1536 × 2048 PNG`。
- 角色在所有图片中必须是同一只萨摩耶：幼年、纯白蓬松双层毛、黑色杏仁眼、黑鼻、微笑嘴、三角立耳、卷在背上的蓬松尾巴。
- 风格：精致 2D 手绘手机养成游戏，圆润、温暖、清晰轮廓，避免写实摄影和 3D 渲染。
- 视角：固定为略微俯视的 3/4 侧面视角，身体朝右；不要改变镜头焦距和身体比例。
- 角色背景：纯色 `#00FF00`，无阴影、无渐变、无文字、无边框、无道具遮挡。后续会统一抠图。
- 每张图给角色四周保留至少 12% 空白；脚掌落点保持一致。

## 提示词 1：角色设定基准图

```text
为一款情侣共同养宠的手机游戏创建角色设定基准图。主角是同一只幼年萨摩耶，全身，纯白蓬松双层毛，黑色杏仁眼和黑鼻子，经典萨摩耶微笑，三角立耳，蓬松卷尾贴在背部，四肢和爪子清楚可见。精致温暖的 2D 手绘养成游戏风格，圆润可爱但保持真实萨摩耶品种特征，不要拟人化，不穿衣服。固定略微俯视的 3/4 侧面视角，身体朝右，自然站立。背景必须是完全均匀的纯 #00FF00，无地面、无投影、无渐变、无纹理。角色居中，四周留 12% 空白。无文字、无水印、无边框、无额外物体。1024×1024 PNG。
```

选定这张后，后续每次生成都把它作为“角色参考图”上传，并附上：

```text
必须严格保持参考图中同一只萨摩耶的脸型、毛色、眼睛、耳朵、尾巴、身体比例、画风、视角和尺寸，只改变指定动作。
```

## 提示词 2：动作序列帧

每个动作单独生成一组，不要让模型把多帧拼在一张图里。将 `{动作}` 分别替换为：

- 自然待机，轻微呼吸
- 向右缓慢行走，右前爪抬起
- 向右缓慢行走，左前爪抬起
- 向右开心奔跑，身体舒展
- 坐下并摇尾巴
- 趴下睡觉，眼睛闭合
- 低头吃狗粮
- 开心叼着飞盘
- 抬起前爪等待摸头
- 洗澡后甩水，毛发蓬松
- 兴奋原地小跳

```text
使用上传的萨摩耶角色基准图作为唯一角色参考。必须是同一只狗，严格保持脸型、身体比例、毛发画法、视角和光线。表现动作：{动作}。全身完整可见，固定略微俯视的 3/4 侧面视角，身体朝右，脚掌落点与参考图一致。精致 2D 手绘手机养成游戏角色资源。背景必须是完全均匀的纯 #00FF00，不得出现地面、接触阴影、渐变、纹理或绿色反光。无文字、无水印、无边框、无额外物体。1024×1024 PNG。
```

## 提示词 3：客厅主场景

```text
为情侣共同养萨摩耶的 2D 手机游戏绘制竖屏主场景。温暖阳光下的治愈客厅，精致手绘养成游戏风格，圆润清晰的形状，固定略微俯视的正面等距视角。中央和下半部分必须保留宽阔、无遮挡、适合小狗自由跑动的浅桃色地毯和木地板。边缘布置：左上角柔软狗窝，右上角狗粮碗和水碗，右下角装有球和飞盘的玩具篮，窗外蓝天白云，少量绿植和爱心相框。暖奶油、蜜桃粉、浅薄荷和天空蓝配色。环境中绝对不要出现狗、人物、文字、按钮、图标、水印或品牌标志。1536×2048 PNG。
```

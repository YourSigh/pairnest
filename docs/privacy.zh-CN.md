# 隐私说明

[English](privacy.md)

PairNest 是一款自托管的情侣应用，可能保存高度敏感的信息。自托管意味着运行服务器的
个人或组织需要承担系统安全、网络、备份和数据处理责任。

本文仅为技术说明，不构成适用于任何地区的法律隐私政策。

## PairNest 保存的数据

根据实际使用的功能，一个实例可能保存：

- 情侣成员位置、设备 Session 和认证元数据
- 聊天文字、回应、已读状态、表情、图片、语音和视频
- 时间线、愿望、纪念日和打卡
- 生理期及其他健康相关记录
- 游戏、扭蛋、报告和共享宠物状态
- AI 对话、记忆、摘要和生成的报告

结构化数据保存在 MySQL 中；上传媒体保存在 `pairnest_uploads` Docker volume 中。

同一套 PairNest API 可以服务多对情侣。每条业务记录都包含 `coupleId`，API 查询按
已认证的情侣空间限定，数据库外键把租户记录关联到所属空间；删除情侣空间时会级联
删除这些记录。这些措施构成 PairNest 的应用层租户边界，但不会把每对情侣隔离到独立
进程、数据库或主机。实例运营者以及拥有数据库、volume 或宿主机权限的人可以访问所有
情侣空间的数据。

## 配对、Session 与恢复

PairNest 对外使用女方和男方两个身份，内部技术值分别为 `partnerA` 和 `partnerB`。
创建人先选择自己的身份，服务端绑定设备后只为相反身份签发邀请；受邀人不能再次自由
选择。确认后的情侣空间和身份会写入 JWT，并与当前 Session 一起校验。
API 和 WebSocket 只使用认证上下文，不信任客户端 Header、Body 或消息中自行声明的
角色。

新邀请由 26 个密码学安全生成的字符组成，24 小时后过期；生成另一枚邀请会替换旧邀请，目标位置
加入后邀请也会失效。目标身份一旦加入过，另一方不能再为其生成接管邀请。女方和男方
分别拥有独立的 26 字符恢复密钥，只能替换对应身份的
Session；密钥会保持有效，直到该成员在已登录设备上主动更新。MySQL 只
保存这些密钥的哈希，但获得有效邀请或恢复密钥的人仍可能加入空间或替换对应成员 Session。
请通过安全渠道分享，不要把它们放进截图、日志、源码、Issue 或未受保护的备份。

移动端会在系统安全存储中保存设备凭证、刷新令牌、本安装唯一的当前成员恢复密钥，以及
尚未完成的创建、激活确认或恢复密钥更新请求；Web 端只能使用浏览器本地存储，其保护强度取决于浏览器和
设备。为处理
“事务已提交但响应丢失”，服务端 Device Session 会暂存创建请求或已消费邀请码的单向
哈希标记；恢复密钥更新还会保存一枚单向链式标记，使同一设备能在普通令牌刷新后继续
取回同一结果。它们不能代替设备私钥；退出、恢复或重新绑定会清除更新链。

过期邀请哈希会按六小时维护周期清理。没有任何设备 Session、也没有成员恢复凭证的旧版
未完成开放空间会在七天后自动删除，因此无主创建流程不能用作长期存储。

退出登录会撤销服务端 Session，并断开对应 WebSocket。使用成员恢复密钥时，服务端会
撤销该身份原有的活动 Session，并以新的 Session ID 重新绑定，避免旧访问令牌复活。
主动更新恢复密钥时，即使成功响应丢失，同一设备也能
重试并取回同一枚新密钥。运营者仍需保护 JWT 签名密钥，并监控公网
实例的异常活动。

## 外部数据处理

默认自托管服务不依赖 AI 或语音转写服务。对应 URL、Key 或模型配置为空时，集成保持
关闭。

启用后：

- AI 供应商可能收到所选功能需要的 Prompt、关系上下文、记忆、标题或近期活动；
- 语音转写供应商会收到用户选择转写的原始音频。

AI 上下文只从当前已认证情侣空间的 PairNest 数据生成；v0.1 不会读取或注入服务端
全局外部上下文目录。AI 和语音转写请求默认在 120 秒后超时；本地超时不代表供应商会
立即停止处理已经收到的请求。

运营者有责任了解供应商的数据保留、训练、访问和数据所在地条款，并在启用前取得两位
伴侣同意。

## 网络、额度与滥用防护

正式 App 必须连接 HTTPS PairNest API。明文 HTTP 仅用于本机或可信局域网开发；否则
网络观察者可以读取认证材料和私密内容。

默认 Compose 不开放 MySQL 端口，API 默认只绑定本机地址。把服务开放到局域网或公网
属于运营者的主动操作。仓库内的 Compose 不会配置域名、反向代理、防火墙或自动 HTTPS。

每对情侣默认拥有 2 GiB 已登记上传文件额度，单个视频默认上限为 100 MiB。匿名创建、
配对校验、设备激活和令牌刷新按 IP 限流；媒体、AI、语音转写、邀请、报告和部分生成
操作按情侣空间限流。这些措施只能作为纵深防护，并不承诺公网实例绝不会被滥用或产生
第三方费用。

## 删除与备份

尚未配对的空间可以立即删除。已经配对的空间需要另一位成员确认；如果对方无法确认，
原申请人可以等待七天后再次确认删除。删除会移除情侣空间、级联业务记录、设备 Session
和已登记媒体文件，并断开这些 Session 的活动 WebSocket。

宿主机权限或存储故障可能导致个别文件暂时删除失败。后台任务会持续重试，运营者仍应
关注 API 日志并核查长期失败的上传 volume。删除操作也无法召回已经由第三方 AI 或
转写供应商处理的数据。

备份包含与在线实例相同的敏感信息。删除情侣空间不会同时删除独立的数据库备份、volume
快照或其他备份。请严格限制访问、制定保留期限并清理过期副本。PairNest v0.1 不提供
加密备份系统。

## 公开仓库卫生

绝对不要提交：

- `.env`、供应商 Key、邀请密钥、恢复密钥或 JWT 密钥
- 数据库导出、Docker volume 或上传文件
- Android/iOS 签名材料
- 生产日志或备份
- 用于品牌或演示的私人照片

公开 fork 前，应运行密钥扫描，并人工检查图片、Prompt、Fixture、示例、文档、lockfile
中的 registry 地址和完整 Git 历史。
